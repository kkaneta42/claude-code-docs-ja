# Slack での Claude Code

> Team、Enterprise、Pro、Max、Ultra プランで、以前の Claude Code in Slack の代わりに使用するもの。

以前の Claude Code in Slack は廃止されました。Claude Tag に接続されていないワークスペースでは、`@Claude` はそのワークスペースが Claude Tag 用にセットアップされていないと返信します。

* **Team および Enterprise プラン：** チャンネルで利用できる場合は [Claude Tag](https://claude.com/docs/claude-tag/overview) を使用してください。利用できない場合は、[セットアップ方法](https://claude.com/docs/claude-tag/admins/setup-overview)を参照してください。以前のバージョンからワークスペースを移行するには、[移行ガイド](https://claude.com/docs/claude-tag/admins/migrate-from-earlier)を参照してください。
* **Pro、Max、Ultra プラン：** Claude Tag は個別プランでは利用できません。アカウントで利用可能な場合は [Projects](https://code.claude.com/docs/ja/claude-projects.md) で、または[クラウドセッション](https://code.claude.com/docs/ja/claude-code-on-the-web.md)でタスクを開始してください。
